# Olist 正式报告分析代码

本目录重算两份报告的全部数字和22幅正式图表。已提交的Word/PDF可直接阅读。命令都在“分析代码”目录中执行；data/raw/需自行创建，放入数据说明所列同批七个SQL文件。

## 环境与依赖

本次验证环境为macOS、Python3.14；requirements.txt锁定本次使用的分析依赖。Windows使用同版本Python时按下列PowerShell命令执行；这些Windows命令尚未在Windows机器上实测。图形需要英文数字Times New Roman及开源中文Noto Serif CJK SC；中文常规和粗体子集与OFL许可已放在assets/report-fonts，代码自动加载，Word中也嵌入中文字体。

## 重算数字与图表

Windows PowerShell：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/reproduce_reports.py
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/reproduce_reports.py
```

默认流程：七个SQL导入临时SQLite→校验业务键与六组外键→内存订单事实表→质量审计与业务指标→22幅PNG/SVG→产物和金额对账。源表键异常时中止，不静默删除。商品维表连接核对行数和金额；缺商品订单仍留在订单总体。

输出在reports/：analysis_snapshot.json和extended_snapshot.json为汇总；evidence/为CSV；figures/editorial/为图形；reproduction.json和reproduction.log记录真实运行状态、环境、输入输出计数、耗时和失败原因。临时SQLite结束后移除；仅校验本次七个SQL的前后SHA256，不校验其他本机数据库。报告代码不默认生成额外网站，也不将明细数据库放进提交材料。

## 重建Word

先在相应系统的虚拟环境安装requirements-documents.txt，再运行同一入口加 --documents。例如Windows：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-documents.txt
.\.venv\Scripts\python.exe scripts/reproduce_reports.py --documents
```

macOS/Linux用 .venv/bin/python 替换上方Python路径。会重建两报告及共用模板；模板是辅助产物，本次必交包不另交模板。

## PDF导出

通用流程：用Word/WPS打开新DOCX，更新目录并导出PDF，再核对实际章起始页、图表和页数。目录是可编辑TOC字段，为防止打开时自动重新分页，初始缓存锁定；需要更新时先解锁目录域。内容修改或换软件后均须重新检查。

自动导出是可选功能，需要可用的Codex documents render_docx.py及其LibreOffice、Poppler运行环境，安装Python依赖并不会安装这些程序。已有该环境时运行：

```sh
python scripts/reproduce_reports.py --documents --render --renderer /absolute/path/render_docx.py
```

python须指向安装文档依赖的虚拟环境；使用不同文档Python可加 --artifact-python。没有该渲染环境时使用前述Word/WPS人工流程。成功生成PDF后才可运行 scripts/verify_pdf_output.py；缺任一份PDF或文件为空时验收必须失败。

## 分析口径和视觉规范

- 订单以order_id去重，含全部状态；商品金额为商品行price合计，不含运费，不等同净收入。评分先同单均值再跨订单均值。
- 配送仅用已送达且实际日期有效订单；延迟按实际与预计日历日期比较；延迟与评分关联用两种条件交集。客户回访按稳定ID，未来观察窗留空。
- 可调参数：low_score_max、state_min_delivery_sample、category_min_orders、cohort_min_customers、cohort_horizon_months。统计、图形和报告相关标签共同使用这些值。
- 固定研究设计：2017年日历；2017/2018年1至8月对照；评分阈值1、2、3及2017/2018年敏感性；延期分段0/3/7/14天；配送图展示0至70天；帕累托80%。这些不是通用配置开关，改变研究设计须同步改报告结构，代码会对不支持的变更报错。
- 主色#28648A，辅色#4B84AA、#77A7C6、#9EC4DA、#C8E0ED；正文黑色，白底。图形保持区域映射一致，辅以点形与线型，不用颜色替代单位和分母。
- 图按章编号、图题在下、表题在上；图题写带数字的发现，下方注明口径、来源和解读。正文11.5磅固定18.5磅行距；中文Noto Serif CJK SC，英文数字Times New Roman。
