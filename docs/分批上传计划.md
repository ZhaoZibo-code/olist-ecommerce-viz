## 第一批运行

按 `docs/数据说明.md` 取得七个 SQL 文件，放在 `data/raw/` 后运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python sql/import_to_sqlite.py
mkdir -p frontend/vendor
.venv/bin/python analysis/pipeline.py
```

Windows 使用 `.venv\Scripts\python.exe` 替代 `.venv/bin/python`，并预先创建 `frontend/vendor` 目录。此批可以生成基础研究图谱和质量摘要。`course_analysis.py` 的完整入口依赖第二批的 `editorial_analysis.py`，待第二批上传后再运行；完整报告及 Web 启动入口也待后续批次补齐。
