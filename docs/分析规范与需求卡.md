# 分析规范与需求卡

## 样式与口径

中文使用Noto Serif CJK SC，英文数字优先Times New Roman。全篇使用中蓝单色系，通过深浅、点形和线型区分类别及对照组。两报告均为A4、分级Word标题、自动目录字段、页码、章内图表编号。图题下写分母、来源及读图解释。

所有结论由 `analysis_snapshot.json` 和 `extended_snapshot.json` 格式化进入正文。比例写清分母，未观察未来窗口留空。关联不写为因果；商品金额不写为净收入；年度不完整时不直接同比。

## 最终问题

这批Olist历史订单的交易集中于何时何地、哪些品类？有效配送、延迟与评分如何关联？稳定客户在首购后月份有多少再次出现？使用者为课程评审及希望理解历史样本交易和履约特征的分析人员。

## 需求卡一 时间覆盖

问题：下单主要集中在哪些月份？为什么查：避免把提取起止当作经营增长。方法：下单日期解析、逐日与逐月计数。结果：99,092 笔在2017年1月至2018年8月；其他月份349笔。决定：全样本保留，年度比较注明不完整；证据months.csv。

## 需求卡二 一对多关联

问题：评价和支付能否直接与商品行联表？为什么查：防止重复金额。方法：按order_id计事件数、复合键查重。结果：547笔订单多评价，2961笔多支付。决定：先按订单聚合后关联，证据checks.csv与extras。

## 需求卡三 区域和品类

问题：规模集中在哪里？为什么查：选择研究优先对象。方法：按客户州和商品品类分组汇总。结果：核心三州金额占63.37%，前18品类累计达80%。决定：优先验证核心组合，不外推全国市场份额；证据states.csv、categories.csv。

## 需求卡四 延迟评分

问题：延迟订单的评分构成是否不同？为什么查：识别体验排查对象。方法：有效配送与有评分交集，订单均分≤2，按延迟组计算比例及Wilson区间；改阈值并按年对照。结果：详见risk.csv、sensitivity.csv。决定：关联用于诊断，不作为因果收益估计。

## 需求卡五 客户回访

问题：观察到首购后次月多少人再次出现？为什么查：避免把订单客户ID误当稳定客户。方法：customer_unique_id首次观察的已送达购买建队列，剔除不完整尾月，未来窗口留空。结果：389 / 81,263，次月回购0.48%。决定：不解释成永久流失；证据cohorts.csv。
