# 交互展示使用说明

启动本地服务后访问 http://127.0.0.1:8780/ ，或用 Chrome、Edge 直接打开 `deliverables/olist_visual_report.html`。页面包含视频、字体、地图和汇总数据，无需联网加载资源。

左右方向键或 PageUp、PageDown 翻页，F 切换全屏。视频需点击播放，可暂停、拖动进度和重播；离开当前页会暂停播放。年份筛选按下单时间生效，页面会标注当前口径。“数据说明”中列出来源、分母、金额对账与分析限制。

离线研究图谱位于 `deliverables/analysis/analysis_report.html`。订单查询页面 `/workbench` 需要本地生成的分析数据库，原始数据获取方式见数据说明。

修改 `scripts/roadshow_template.html` 后，运行 `python scripts/build_report.py` 重建展示。该脚本使用 `video/olist-vibe/` 中随仓库提供的视频、封面和字体资源。
